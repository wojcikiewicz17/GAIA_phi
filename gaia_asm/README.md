# gaia_asm

Módulo de build nativo ASM/C do projeto **GAIA_phi**.

## Estrutura
- `asm/` — rotinas assembly.
- `src/` — integração C e wrappers de execução.
- `include/` — headers públicos do módulo.

## Objetivo
Prover trilha nativa de baixo nível para validação de desempenho, portabilidade e integração com o pipeline principal.
